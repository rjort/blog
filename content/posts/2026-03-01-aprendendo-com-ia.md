# Log: aprendendo com IA

## Introducao ao aprendizado assistido

A inteligência artificial transformou radicalmente a maneira como aprendemos programação e engenharia de software. Não se trata apenas de autocompletar código, mas de ter um parceiro de pair programming disponível 24/7.

## Principais abordagens

### 1. Explicacao de conceitos complexos
Você pode pedir para a IA explicar código legado ou algoritmos avançados com analogias personalizadas.

```bash
$ antigravity explain "Como funciona a alocação de memória no Ruby 4?"
```

### 2. Criacao de planos de estudo
Estruturar o aprendizado de novas tecnologias em etapas graduais.

## Boas praticas no uso de agentes

- **Verifique a documentação oficial**: Sempre confirme os conceitos com a documentação do ecossistema.
- **Faça perguntas específicas**: Quanto melhor o contexto fornecido, mais precisa é a resposta.
- **Escreva o código você mesmo**: Use a IA para entender o motivo das coisas, mas exercite a escrita manual.
